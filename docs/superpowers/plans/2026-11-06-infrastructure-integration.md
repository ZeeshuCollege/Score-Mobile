# SCORE Production Infrastructure Integration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate Cloudflare R2 (file storage), Cloudflare CDN (asset delivery), Firebase Cloud Messaging (push notifications) into the existing SCORE Flutter app while auditing and strengthening the existing Supabase integration.

**Architecture:** Server-side-only credentials; Flutter client never holds R2 or FCM server keys. File uploads use presigned URLs generated by Supabase Edge Functions. FCM notifications are sent via Edge Functions using the HTTP v1 API. All secrets live in Supabase Edge Function environment secrets. The Flutter app adds three service layers (R2, FCM, CDN) alongside the existing Supabase/SQLite layers without replacing them.

**Tech Stack:** Flutter 3.47.4 / Dart 3.13.3, Riverpod 3.4.3, Supabase Flutter 2.18.3, firebase_core + firebase_messaging, Deno (Edge Functions), AWS S3-compatible API for R2 presigned URLs.

**Spec:** This plan file is the spec. The original user request is the authoritative requirement document.

## Review Focus

- **R2 presigned URL leakage:** presigned URLs must never appear in Flutter logs, error messages, or be persisted beyond the upload/download operation; test that `debugPrint` is absent from all R2 service calls
- **RLS policy gaps:** any new Supabase table must have RLS enabled and policies covering all four operations; a table with RLS ON but no policies is effectively locked out
- **FCM token orphan on logout:** when a user logs out, their FCM token for that device must be deactivated in `device_tokens`; test that logout triggers token deactivation
- **Duplicate file ownership:** a user must not be able to request a presigned URL for another user's private object key; test that the Edge Function rejects cross-user key access
- **Background message handler registration:** `FirebaseMessaging.onBackgroundMessage` must be a top-level function, not a closure or class method; verify placement in `main.dart` before `runApp`

- Consumes: Supabase JWT from `Authorization: Bearer <token>` header (standard Supabase auth)
- Environment secrets consumed: `CLOUDFLARE_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_PUBLIC`, `R2_BUCKET_PRIVATE`, `R2_ENDPOINT`

- [ ] **Step 1: Create supabase/functions directory structure**

Create: `supabase/functions/r2-presign/index.ts`

The function must:

1. Validate the JWT using `Supabase.createClient` with service role key (from env `SUPABASE_SERVICE_ROLE_KEY`)
2. Extract `user_id` from the JWT
3. Validate `operation`, `bucket`, `file_category`, `mime_type`, `file_size` from request body
4. For upload: generate a unique `object_key` = `{user_id}/{file_category}/{nanoid()}.{ext}`
5. For download: verify `object_key` starts with `{user_id}/` for private bucket (ownership check)
6. Generate AWS Signature V4 presigned URL using native Deno crypto (no external SDK)
7. Return `{presigned_url, object_key, expires_at}` — never log the presigned URL
8. Upload expiry: 900 seconds (15 minutes); download expiry: 3600 seconds (60 minutes)

Validation rules:

- Max file size: 52428800 bytes (50 MB)
- Allowed MIME types for upload: `["image/jpeg", "image/png", "image/webp", "image/gif", "application/pdf"]`
- Allowed file categories: `["question_images", "question_diagrams", "educational_pdfs", "study_materials", "user_documents"]`
- Private bucket only for category `"user_documents"`
- Public bucket for all other categories
- Never trust client-provided MIME type as final truth; use it only for the presigned URL content-type header

```typescript
// supabase/functions/r2-presign/index.ts
import { createClient } from "https://esm.sh/@supabase/supabase-js@2";
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";

const CORS_HEADERS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers":
    "authorization, x-client-info, apikey, content-type",
  "Access-Control-Allow-Methods": "POST, OPTIONS",
};

const ALLOWED_MIME_TYPES = [
  "image/jpeg",
  "image/png",
  "image/webp",
  "image/gif",
  "application/pdf",
];
const ALLOWED_CATEGORIES = [
  "question_images",
  "question_diagrams",
  "educational_pdfs",
  "study_materials",
  "user_documents",
];
const PRIVATE_CATEGORIES = ["user_documents"];
const MAX_FILE_SIZE = 52428800; // 50MB

// AWS Signature V4 implementation using Deno native crypto
async function hmacSha256(
  key: ArrayBuffer | string,
  data: string,
): Promise<ArrayBuffer> {
  const keyMaterial =
    typeof key === "string" ? new TextEncoder().encode(key) : key;
  const cryptoKey = await crypto.subtle.importKey(
    "raw",
    keyMaterial,
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"],
  );
  return crypto.subtle.sign("HMAC", cryptoKey, new TextEncoder().encode(data));
}

async function sha256Hex(data: string): Promise<string> {
  const hash = await crypto.subtle.digest(
    "SHA-256",
    new TextEncoder().encode(data),
  );
  return Array.from(new Uint8Array(hash))
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");
}

function toHex(buffer: ArrayBuffer): string {
  return Array.from(new Uint8Array(buffer))
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");
}

function getExtension(mimeType: string): string {
  const map: Record<string, string> = {
    "image/jpeg": "jpg",
    "image/png": "png",
    "image/webp": "webp",
    "image/gif": "gif",
    "application/pdf": "pdf",
  };
  return map[mimeType] ?? "bin";
}

function generateId(): string {
  const bytes = new Uint8Array(12);
  crypto.getRandomValues(bytes);
  return Array.from(bytes)
    .map((b) => b.toString(36))
    .join("")
    .substring(0, 16);
}

async function generatePresignedUrl(params: {
  operation: "upload" | "download";
  bucket: string;
  objectKey: string;
  mimeType: string;
  expirySeconds: number;
  endpoint: string;
  accessKeyId: string;
  secretAccessKey: string;
  region: string;
}): Promise<string> {
  const {
    operation,
    bucket,
    objectKey,
    mimeType,
    expirySeconds,
    endpoint,
    accessKeyId,
    secretAccessKey,
    region,
  } = params;
  const method = operation === "upload" ? "PUT" : "GET";
  const now = new Date();
  const dateStamp = now.toISOString().replace(/[-:]/g, "").substring(0, 8);
  const amzDate = now.toISOString().replace(/[-:]/g, "").substring(0, 15) + "Z";
  const credentialScope = `${dateStamp}/${region}/s3/aws4_request`;
  const credential = `${accessKeyId}/${credentialScope}`;

  const url = new URL(`${endpoint}/${bucket}/${objectKey}`);
  url.searchParams.set("X-Amz-Algorithm", "AWS4-HMAC-SHA256");
  url.searchParams.set("X-Amz-Credential", credential);
  url.searchParams.set("X-Amz-Date", amzDate);
  url.searchParams.set("X-Amz-Expires", String(expirySeconds));
  url.searchParams.set("X-Amz-SignedHeaders", "host");
  if (operation === "upload") {
    url.searchParams.set("X-Amz-Content-Type", mimeType);
  }

  const sortedParams = [...url.searchParams.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .map(([k, v]) => `${encodeURIComponent(k)}=${encodeURIComponent(v)}`)
    .join("&");

  const canonicalRequest = [
    method,
    `/${bucket}/${objectKey}`,
    sortedParams,
    `host:${url.hostname}`,
    "",
    "host",
    "UNSIGNED-PAYLOAD",
  ].join("\n");

  const stringToSign = [
    "AWS4-HMAC-SHA256",
    amzDate,
    credentialScope,
    await sha256Hex(canonicalRequest),
  ].join("\n");

  const kDate = await hmacSha256(`AWS4${secretAccessKey}`, dateStamp);
  const kRegion = await hmacSha256(kDate, region);
  const kService = await hmacSha256(kRegion, "s3");
  const kSigning = await hmacSha256(kService, "aws4_request");
  const signature = toHex(await hmacSha256(kSigning, stringToSign));

  url.searchParams.set("X-Amz-Signature", signature);
  return url.toString();
}

serve(async (req) => {
  if (req.method === "OPTIONS")
    return new Response(null, { headers: CORS_HEADERS });
  if (req.method !== "POST")
    return new Response("Method not allowed", {
      status: 405,
      headers: CORS_HEADERS,
    });

  try {
    const authHeader = req.headers.get("Authorization");
    if (!authHeader?.startsWith("Bearer ")) {
      return new Response(JSON.stringify({ error: "Missing authorization" }), {
        status: 401,
        headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
      });
    }

    const supabase = createClient(
      Deno.env.get("SUPABASE_URL")!,
      Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!,
    );
    const {
      data: { user },
      error: authError,
    } = await supabase.auth.getUser(authHeader.split(" ")[1]);
    if (authError || !user) {
      return new Response(JSON.stringify({ error: "Unauthorized" }), {
        status: 401,
        headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
      });
    }

    const body = await req.json();
    const {
      operation,
      file_category,
      mime_type,
      file_size,
      object_key: requestedKey,
    } = body;

    // Validate inputs
    if (!["upload", "download"].includes(operation)) {
      return new Response(JSON.stringify({ error: "Invalid operation" }), {
        status: 400,
        headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
      });
    }
    if (!ALLOWED_CATEGORIES.includes(file_category)) {
      return new Response(JSON.stringify({ error: "Invalid file_category" }), {
        status: 400,
        headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
      });
    }

    const isPrivate = PRIVATE_CATEGORIES.includes(file_category);
    const bucketName = isPrivate
      ? Deno.env.get("R2_BUCKET_PRIVATE")!
      : Deno.env.get("R2_BUCKET_PUBLIC")!;

    let objectKey: string;
    if (operation === "upload") {
      if (!ALLOWED_MIME_TYPES.includes(mime_type)) {
        return new Response(
          JSON.stringify({ error: "Unsupported file type" }),
          {
            status: 400,
            headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
          },
        );
      }
      if (
        typeof file_size !== "number" ||
        file_size <= 0 ||
        file_size > MAX_FILE_SIZE
      ) {
        return new Response(JSON.stringify({ error: "Invalid file size" }), {
          status: 400,
          headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
        });
      }
      const ext = getExtension(mime_type);
      objectKey = `${user.id}/${file_category}/${generateId()}.${ext}`;
    } else {
      // download
      if (!requestedKey || typeof requestedKey !== "string") {
        return new Response(
          JSON.stringify({ error: "object_key required for download" }),
          {
            status: 400,
            headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
          },
        );
      }
      // Ownership check for private objects
      if (isPrivate && !requestedKey.startsWith(`${user.id}/`)) {
        return new Response(JSON.stringify({ error: "Access denied" }), {
          status: 403,
          headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
        });
      }
      objectKey = requestedKey;
    }

    const expirySeconds = operation === "upload" ? 900 : 3600;
    const presignedUrl = await generatePresignedUrl({
      operation,
      bucket: bucketName,
      objectKey,
      mimeType: mime_type ?? "application/octet-stream",
      expirySeconds,
      endpoint: Deno.env.get("R2_ENDPOINT")!,
      accessKeyId: Deno.env.get("R2_ACCESS_KEY_ID")!,
      secretAccessKey: Deno.env.get("R2_SECRET_ACCESS_KEY")!,
      region: "auto",
    });

    const expiresAt = new Date(Date.now() + expirySeconds * 1000).toISOString();
    // IMPORTANT: Never log the presignedUrl
    return new Response(
      JSON.stringify({
        presigned_url: presignedUrl,
        object_key: objectKey,
        expires_at: expiresAt,
      }),
      {
        status: 200,
        headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
      },
    );
  } catch (err) {
    // Never expose internal error details
    console.error(
      "r2-presign error:",
      err instanceof Error ? err.message : "unknown",
    );
    return new Response(JSON.stringify({ error: "Internal server error" }), {
      status: 500,
      headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
    });
  }
});
```

```typescript
import { createClient } from "https://esm.sh/@supabase/supabase-js@2";
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";

const CORS_HEADERS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers":
    "authorization, x-client-info, apikey, content-type",
  "Access-Control-Allow-Methods": "POST, OPTIONS",
};

// Get Google OAuth2 access token from service account
async function getAccessToken(serviceAccountJson: string): Promise<string> {
  const sa = JSON.parse(serviceAccountJson);
  const now = Math.floor(Date.now() / 1000);
  const header = { alg: "RS256", typ: "JWT" };
  const payload = {
    iss: sa.client_email,
    scope: "https://www.googleapis.com/auth/firebase.messaging",
    aud: "https://oauth2.googleapis.com/token",
    iat: now,
    exp: now + 3600,
  };

  const encodeBase64Url = (str: string) =>
    btoa(str).replace(/\+/g, "-").replace(/\//g, "_").replace(/=/g, "");

  const headerB64 = encodeBase64Url(JSON.stringify(header));
  const payloadB64 = encodeBase64Url(JSON.stringify(payload));
  const signingInput = `${headerB64}.${payloadB64}`;

  // Import RSA private key
  const pemBody = sa.private_key
    .replace("-----BEGIN PRIVATE KEY-----", "")
    .replace("-----END PRIVATE KEY-----", "")
    .replace(/\s/g, "");
  const keyBuffer = Uint8Array.from(atob(pemBody), (c) => c.charCodeAt(0));
  const privateKey = await crypto.subtle.importKey(
    "pkcs8",
    keyBuffer,
    { name: "RSASSA-PKCS1-v1_5", hash: "SHA-256" },
    false,
    ["sign"],
  );

  const signature = await crypto.subtle.sign(
    "RSASSA-PKCS1-v1_5",
    privateKey,
    new TextEncoder().encode(signingInput),
  );
  const signatureB64 = encodeBase64Url(
    String.fromCharCode(...new Uint8Array(signature)),
  );
  const jwt = `${signingInput}.${signatureB64}`;

  const tokenResp = await fetch("https://oauth2.googleapis.com/token", {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: `grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer&assertion=${jwt}`,
  });
  const tokenData = await tokenResp.json();
  if (!tokenData.access_token)
    throw new Error("Failed to get FCM access token");
  return tokenData.access_token;
}

      const message = {
        message: {
          token: tokenRecord.fcm_token,
          notification: { title, body: notifBody },
          data: extraData ?? {},
        },
      };

      const fcmResp = await fetch(
        `https://fcm.googleapis.com/v1/projects/${projectId}/messages:send`,
        {
          method: "POST",
          headers: {
            Authorization: `Bearer ${accessToken}`,
            "Content-Type": "application/json",
          },
          body: JSON.stringify(message),
        },
      );

      if (fcmResp.ok) {
        sentCount++;
      } else {
        const errData = await fcmResp.json();
        const errCode = errData?.error?.details?.[0]?.errorCode;
        if (["UNREGISTERED", "INVALID_ARGUMENT"].includes(errCode)) {
          invalidTokenIds.push(tokenRecord.id);
        }
        // Log error code only, never the token itself
        console.error("FCM send error:", errCode ?? fcmResp.status);
      }
    }

    // Deactivate invalid tokens
    if (invalidTokenIds.length > 0) {
      await supabase
        .from("device_tokens")
        .update({ is_active: false, updated_at: new Date().toISOString() })
        .in("id", invalidTokenIds);
    }

    return new Response(
      JSON.stringify({ success: true, sent_count: sentCount }),
      {
        status: 200,
        headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
      },
    );
  } catch (err) {
    console.error(
      "send-notification error:",
      err instanceof Error ? err.message : "unknown",
    );
    return new Response(JSON.stringify({ error: "Internal server error" }), {
      status: 500,
      headers: { ...CORS_HEADERS, "Content-Type": "application/json" },
    });
  }
});
```

```dart
class R2PresignResult {
  final String presignedUrl;
  final String objectKey;
  final DateTime expiresAt;
  const R2PresignResult({required this.presignedUrl, required this.objectKey, required this.expiresAt});
}

/// Handles Cloudflare R2 presigned URL requests via Supabase Edge Function.
/// Never stores or logs presigned URLs beyond the immediate operation.
class CloudflareR2Service {
  CloudflareR2Service._();
  static final CloudflareR2Service instance = CloudflareR2Service._();

  /// Request a presigned upload URL for a file.
  Future<R2PresignResult?> requestUploadUrl({
    required String fileCategory,
    required String mimeType,
    required int fileSize,
  }) async {
    try {
      final client = Supabase.instance.client;
      final response = await client.functions.invoke(
        'r2-presign',
        body: {
          'operation': 'upload',
          'file_category': fileCategory,
          'mime_type': mimeType,
          'file_size': fileSize,
        },
      );
      final data = response.data as Map<String, dynamic>?;
      if (data == null || data['presigned_url'] == null) return null;
      return R2PresignResult(
        presignedUrl: data['presigned_url'] as String,
        objectKey: data['object_key'] as String,
        expiresAt: DateTime.parse(data['expires_at'] as String),
      );
    } catch (e) {
      debugPrint('CloudflareR2Service: upload URL request failed');
      return null;
    }
  }

  /// Request a presigned download URL for a private file.
  Future<String?> requestDownloadUrl({
    required String objectKey,
    required String fileCategory,
  }) async {
    try {
      final client = Supabase.instance.client;
      final response = await client.functions.invoke(
        'r2-presign',
        body: {
          'operation': 'download',
          'file_category': fileCategory,
          'object_key': objectKey,
        },
      );
      final data = response.data as Map<String, dynamic>?;
      return data?['presigned_url'] as String?;
    } catch (e) {
      debugPrint('CloudflareR2Service: download URL request failed');
      return null;
    }
  }

  /// Upload a file directly to R2 using a presigned PUT URL.
  /// Returns true on success. The presigned URL is used once and not stored.
  Future<bool> uploadFileDirect({
    required String presignedUrl,
    required File file,
    required String mimeType,
  }) async {
    try {
      final bytes = await file.readAsBytes();
      final response = await http.put(
        Uri.parse(presignedUrl),
        headers: {'Content-Type': mimeType},
        body: bytes,
      );
      return response.statusCode == 200;
    } catch (e) {
      debugPrint('CloudflareR2Service: direct upload failed');
      return false;
    }
  }
}
```

```dart
import 'dart:io';
import 'package:flutter/foundation.dart';
import 'package:supabase_flutter/supabase_flutter.dart';
import 'cloudflare_r2_service.dart';

enum FileCategory {
  questionImages('question_images'),
  questionDiagrams('question_diagrams'),
  educationalPdfs('educational_pdfs'),
  studyMaterials('study_materials'),
  userDocuments('user_documents');

  final String value;
  const FileCategory(this.value);
}

class FileUploadResult {
  final bool success;
  final String? objectKey;
  final String? errorMessage;
  const FileUploadResult({required this.success, this.objectKey, this.errorMessage});
}

/// Orchestrates the full file upload flow:
/// 1. Request presigned URL from server
/// 2. Upload directly to R2
/// 3. Record metadata in Supabase
class FileUploadService {
  FileUploadService._();
  static final FileUploadService instance = FileUploadService._();

  static const int _maxFileSizeBytes = 52428800; // 50MB
  static const List<String> _allowedMimeTypes = [
    'image/jpeg', 'image/png', 'image/webp', 'image/gif', 'application/pdf'
  ];

  Future<FileUploadResult> uploadFile({
    required File file,
    required String mimeType,
    required FileCategory category,
    required String originalFileName,
  }) async {
    // Client-side validation (server also validates)
    final fileSize = await file.length();
    if (fileSize > _maxFileSizeBytes) {
      return const FileUploadResult(success: false, errorMessage: 'File exceeds 50 MB limit');
    }
    if (!_allowedMimeTypes.contains(mimeType)) {
      return const FileUploadResult(success: false, errorMessage: 'File type not supported');
    }

    // Step 1: Get presigned upload URL
    final presignResult = await CloudflareR2Service.instance.requestUploadUrl(
      fileCategory: category.value,
      mimeType: mimeType,
      fileSize: fileSize,
    );
    if (presignResult == null) {
      return const FileUploadResult(success: false, errorMessage: 'Failed to get upload authorization');
    }

    // Step 2: Upload to R2 directly
    final uploaded = await CloudflareR2Service.instance.uploadFileDirect(
      presignedUrl: presignResult.presignedUrl,
      file: file,
      mimeType: mimeType,
    );
    if (!uploaded) {
      return const FileUploadResult(success: false, errorMessage: 'File upload failed');
    }

    // Step 3: Record metadata in Supabase
    try {
      final client = Supabase.instance.client;
      final userId = client.auth.currentUser?.id;
      if (userId == null) {
        return const FileUploadResult(success: false, errorMessage: 'Not authenticated');
      }
      await client.from('file_uploads').insert({
        'owner_id': userId,
        'bucket_name': category == FileCategory.userDocuments
            ? 'score-private-uploads'
            : 'score-public-assets',
        'object_key': presignResult.objectKey,
        'original_file_name': originalFileName,
        'mime_type': mimeType,
        'file_size': fileSize,
        'file_category': category.value,
        'visibility': category == FileCategory.userDocuments ? 'private' : 'public',
        'upload_status': 'completed',
      });
    } catch (e) {
      debugPrint('FileUploadService: metadata recording failed');
      // Upload succeeded even if metadata recording failed; return success with key
    }

    return FileUploadResult(success: true, objectKey: presignResult.objectKey);
  }
}
```

```dart
import 'package:flutter/foundation.dart';
import 'package:firebase_messaging/firebase_messaging.dart';

enum NotificationPermissionStatus { granted, denied, permanentlyDenied, notDetermined }

/// Handles notification permission requests using FCM API.
/// Permissions must NOT be requested at cold launch — only contextually.
class NotificationPermissionService {
  NotificationPermissionService._();
  static final NotificationPermissionService instance = NotificationPermissionService._();

  /// Request notification permission. Call only at an appropriate contextual moment,
  /// never at app cold start.
  Future<NotificationPermissionStatus> requestPermission() async {
    if (kIsWeb) return NotificationPermissionStatus.notDetermined;

    try {
      final settings = await FirebaseMessaging.instance.requestPermission(
        alert: true,
        badge: true,
        sound: true,
        provisional: false,
      );
      return _mapAuthStatus(settings.authorizationStatus);
    } catch (e) {
      debugPrint('NotificationPermissionService: request failed');
      return NotificationPermissionStatus.notDetermined;
    }
  }

  /// Check current permission status without requesting.
  Future<NotificationPermissionStatus> checkPermissionStatus() async {
    if (kIsWeb) return NotificationPermissionStatus.notDetermined;
    try {
      final settings = await FirebaseMessaging.instance.getNotificationSettings();
      return _mapAuthStatus(settings.authorizationStatus);
    } catch (e) {
      return NotificationPermissionStatus.notDetermined;
    }
  }

  NotificationPermissionStatus _mapAuthStatus(AuthorizationStatus status) {
    switch (status) {
      case AuthorizationStatus.authorized:
        return NotificationPermissionStatus.granted;
      case AuthorizationStatus.denied:
        return !Platform.isIOS
            ? NotificationPermissionStatus.permanentlyDenied
            : NotificationPermissionStatus.denied;
      case AuthorizationStatus.provisional:
        return NotificationPermissionStatus.granted; // Provisional = quiet delivery on iOS
      case AuthorizationStatus.notDetermined:
        return NotificationPermissionStatus.notDetermined;
    }
  }
}
```

```dart
    try {
      final client = Supabase.instance.client;
      final userId = client.auth.currentUser?.id;
      if (userId == null) return;

      final deviceId = await _getDeviceId();
      await client.from('device_tokens')
          .update({'is_active': false, 'updated_at': DateTime.now().toUtc().toIso8601String()})
          .eq('user_id', userId)
          .eq('device_id', deviceId);

      debugPrint('DeviceTokenService: token deactivated on logout');
    } catch (e) {
      debugPrint('DeviceTokenService: deactivation failed');
    }
  }

  Future<void> _updateToken({
    required String userId,
    required String deviceId,
    required String token,
    required String platform,
  }) async {
    try {
      final client = Supabase.instance.client;
      await client.from('device_tokens').upsert({
        'user_id': userId,
        'device_id': deviceId,
        'fcm_token': token,
        'platform': platform,
        'is_active': true,
        'notification_enabled': true,
        'last_seen_at': DateTime.now().toUtc().toIso8601String(),
        'updated_at': DateTime.now().toUtc().toIso8601String(),
      }, onConflict: 'user_id,device_id');
    } catch (e) {
      debugPrint('DeviceTokenService: token update failed');
    }
  }

  Future<String> _getDeviceId() async {
    try {
      final deviceInfo = DeviceInfoPlugin();
      if (Platform.isAndroid) {
        final info = await deviceInfo.androidInfo;
        return info.id;
      } else if (Platform.isIOS) {
        final info = await deviceInfo.iosInfo;
        return info.identifierForVendor ?? 'unknown-ios';
      }
    } catch (_) {}
    return 'unknown-device';
  }
}
```
